### [Xcode](https://developer.apple.com/xcode)

#### Installation

1. Create the custom themes folder:

```bash
mkdir ~/Library/Developer/Xcode/UserData/FontAndColorThemes/
```

2. Move `dracula-pro.xccolortheme` file to this custom themes folder.

> Close Xcode before moving the theme file so it loads correctly on next launch.

#### Activating theme

1. Go to `Xcode > Preferences > Themes`.
2. Select the Dracula theme.
3. If the theme is missing, restart Xcode and check the folder path.
