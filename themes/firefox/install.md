### [Mozilla Firefox](https://www.mozilla.org/firefox)

#### Installation

1. Open Firefox.
2. In the address bar, type `about:addons` and press Enter.
3. In the left sidebar, click **Themes**.
4. Click the gear icon near the top of the page.
5. Choose **Install Add-on From File...**
6. Select the `.xpi` file for the theme you want and confirm.

#### Activating the theme

The theme usually turns on right after you install it.

If Firefox still looks the same, go back to **Themes** and click **Enable** next to Dracula Pro.
