### [Zsh](http://zsh.org)

#### Installation

> If this is your first Zsh setup, install OhMyZsh first and then come back to these steps.

1. Install [oh-my-zsh](https://github.com/robbyrussell/oh-my-zsh).
2. Move `dracula-pro.zsh-theme` file to oh-my-zsh's theme folder: `~/.oh-my-zsh/themes/dracula-pro.zsh-theme`.

#### Activating theme

1. Go to your `~/.zshrc` file and set `ZSH_THEME="dracula-pro"`.
2. Save the file and run `source ~/.zshrc`, or open a new terminal window.
