### [Google Chrome](https://www.google.com/chrome)

#### Installation

1. Type `chrome://extensions` in the address bar.
2. Select the "Developer mode" checkbox.
3. Click the "Load unpacked" button.
4. Choose the "dracula-pro" directory.

#### Activating theme

The theme will be activated automatically after installation.

> If it does not activate, refresh the Extensions page and re-enable the loaded theme.
