### [Zed](https://zed.dev)

#### Installation

1. Copy the `dracula-pro.json` file to `~/.config/zed/themes`.

> If the `~/.config/zed/themes` folder does not exist, create it first.

#### Activating theme

1. Select one of the Dracula Pro variations.
2. The theme will be activated automatically.
3. Restart Zed if the theme list does not update.
