### [Terminal.app](<https://en.wikipedia.org/wiki/Terminal_(macOS)>)

#### Installation

> Open Terminal.app first, and keep the `dracula-pro.terminal` file easy to find.

1. Go to `Terminal > Profiles` tab.
2. Click the "Gear" icon.
3. Click `Import...`.
4. Select the `dracula-pro.terminal` file.
5. If prompted, confirm the import.

#### Activating theme

1. Click `Default` to set it as the default profile.
2. Open a new terminal window to confirm the theme is active.
