### [iTerm 2](https://www.iterm2.com/)

#### Installation

> Open iTerm 2 before starting, and keep the theme file easy to find.

1. Go to `Preferences > Profiles > Colors` tab.
2. Open the _Color Presets..._ drop-down in the bottom right corner.
3. Select _Import..._ from the list.
4. Select the `dracula-pro.itermcolors` file.

#### Activating theme

1. Select the _Dracula Pro_ from _Color Presets..._.
2. Open a new tab to verify the colors were applied.
