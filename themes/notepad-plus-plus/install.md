### [Notepad++](https://notepad-plus-plus.org/)

#### Installation

> Close Notepad++ before copying the theme file so it is detected on launch.

1. Go to `%AppData%\Notepad++\themes`.
2. Place the variant XML file inside that folder (for example `dracula-pro.xml`, `dracula-pro-alucard.xml`, `dracula-pro-blade.xml`, `dracula-pro-buffy.xml`, `dracula-pro-lincoln.xml`, `dracula-pro-morbius.xml`, `dracula-pro-nosferatu.xml`, or `dracula-pro-van-helsing.xml`).

> Note: `%AppData%` is a platform-dependent environment variable. Open Command Prompt and run `echo %AppData%`.

#### Activating theme

1. Restart Notepad++.
2. Your chosen variant will be available in `Settings > Style Configurator > Theme`.

#### Known limitations

Notepad++ does not offer syntax highlighting for Markdown files yet.
