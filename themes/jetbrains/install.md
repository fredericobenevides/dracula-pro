### [JetBrains IDE](https://www.jetbrains.com)

#### Installation

1. Go to `Settings -> Plugins`.
2. Click the gear icon at the top.
3. Select `Install Plugin from Disk...`.
4. Choose the ZIP file.
5. Restart the IDE when prompted.

#### Activating theme

1. Open `Settings -> Appearance & Behavior -> Appearance`.
2. Select a Dracula Pro palette, or an Islands variant.
3. The matching editor color scheme is applied automatically.

#### Requirements

- JetBrains IDE 2025.3 or later.
